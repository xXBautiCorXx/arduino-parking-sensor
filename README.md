# Arduino Parking Sensor

An Arduino-based parking assistance system designed to detect nearby obstacles using ultrasonic distance sensing.

## 📖 Description

This project simulates the functionality of real vehicle parking sensors by detecting the distance between the system and nearby objects.

The system provides proximity feedback and can be expanded with visual or audio alerts for improved usability.

## ⚙️ Features

- Real-time distance detection
- Obstacle proximity monitoring
- Compact and simple design
- Based on ultrasonic sensing technology
- Beginner-friendly embedded systems project

## 🛠️ Technologies & Components

### Software
- Arduino IDE
- C/C++

### Hardware
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- LEDs / Buzzer (optional)
- Breadboard
- Jumper wires

## 🔌 How It Works

The ultrasonic sensor continuously measures the distance to nearby objects.

Based on the measured distance, the system can trigger alerts or indicators to simulate a real parking assistance system.
